# azureacme Provider

Manages durable certificate registrations through a Mantisec ACME certificate service. An `azureacme_certificate` is a standing instruction to keep a certificate valid, not one signed artefact.

Read that second sentence twice before reading anything else. Terraform manages the *instruction*;
the service continuously fulfils it — issuing, renewing and republishing into your Key Vault — even
when Terraform has not run for months. Nearly every surprising behaviour in this provider follows
from that split: `terraform plan` reports no change the day after a renewal, `id` never contains a
version or a thumbprint, and destroying the resource destroys the instruction rather than,
necessarily, the certificate.

## Example Usage

```terraform
# tfplugindocs input. The path is fixed by the tool: this snippet becomes the
# usage section of the generated provider index page.

terraform {
  required_providers {
    azureacme = {
      source = "mantisec/azureacme"
    }
  }
}

# Preferred: one object emitted by the platform module. Because
# expected_service_instance_id travels inside it, the mistyped-endpoint safety
# rail is on by default for anyone who copies the module output.
provider "azureacme" {
  connection_profile = var.acme_connection_profile
}

# The service is deployed by a SEPARATE Terraform configuration. A provider
# cannot be configured from a resource created in the same apply, so the
# endpoint arrives here as a variable — never as module.platform.endpoint.
variable "acme_connection_profile" {
  type = object({
    endpoint                     = string
    audience                     = string
    tenant_id                    = string
    expected_service_instance_id = optional(string)
  })
}
```

~> **Never obtain the publishing identity by reading the platform workspace's state.** A
remote-state data source pointed at that state grants the reading workspace access to its storage
account keys and its full resource graph — a privilege escalation dressed as convenience.
`data.azureacme_service.this.publisher_principal_id` exists so the secure path is also the short
one.

## Schema

### Optional

- `audience` (String) Token audience. **Required** — set it here, in `connection_profile`, or in `MANTISEC_ACME_AUDIENCE`. Operator-configured; MUST NOT be derived from an unauthenticated `/v1/capabilities` call. A reported mismatch is warned about, never acted on.
- `client_certificate_password` (String, Sensitive) Password for the client certificate.
- `client_certificate_path` (String) Path to a client certificate.
- `client_id` (String) Entra client id of the calling identity. **Mandatory on the managed-identity path**: with more than one user-assigned identity attached, an unqualified IMDS request can silently return the wrong identity's token. Falls back to `MANTISEC_ACME_CLIENT_ID`, `ARM_CLIENT_ID`, `AZURE_CLIENT_ID`.
- `connection_profile` (Attributes) The connection object emitted by the platform module. Mutually exclusive with `endpoint`, `audience`, `tenant_id` and `expected_service_instance_id`. (see [below for nested schema](#nestedatt--connection_profile))
- `endpoint` (String) Base URL of the service. Falls back to `MANTISEC_ACME_ENDPOINT`.
- `environment` (String) `public`, `usgovernment` or `china`. Drives the authority host and the Key Vault DNS suffix.
- `expected_service_instance_id` (String) Checked once at Configure, before any resource is touched.
- `max_retries` (Number) Defaults to `5`.
- `oidc_request_token` (String, Sensitive) GitHub Actions OIDC request token.
- `oidc_request_url` (String) GitHub Actions OIDC request URL.
- `oidc_token` (String, Sensitive) OIDC token. Prefer the environment variable.
- `oidc_token_file_path` (String) Path to a file containing the OIDC token.
- `request_timeout` (String) Per-HTTP-request timeout, not per operation. Defaults to `60s`.
- `skip_instance_check` (Boolean) Skips service-instance pinning only. Emits a warning.
- `skip_version_check` (Boolean) Skips the version assertions only. Emits a warning.
- `tenant_id` (String) Entra tenant id. Falls back to `MANTISEC_ACME_TENANT_ID`, `ARM_TENANT_ID`, `AZURE_TENANT_ID`.
- `use_cli` (Boolean) Gate on the last step of the ambient credential chain, the Azure CLI identity. Tried last, and only when no explicit method is configured. Defaults to `true`.
- `use_msi` (Boolean) Authenticate with a managed identity.
- `use_oidc` (Boolean) Authenticate with a federated OIDC token.
